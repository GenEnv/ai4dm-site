## Notes

- `v1/` and `v2/` are static exports from Notion; inner page filenames keep their Notion export IDs (renaming them would break internal links). Only the two entry pages are renamed to `index.html`.
- Images are downsampled to ≤1600px wide for web delivery.
- This repo hosts the published site only; the platform source lives in a separate private repo.
